---
title: Install in Claude Code
description: Install the obsidian-wiki plugin from the Claude Code CLI
---

Install obsidian-wiki from inside the Claude Code CLI with two slash commands. This path requires Claude Code with plugins enabled.

```bash
# from inside Claude Code
/plugin marketplace add giovi321/obsidian-wiki
/plugin install obsidian-wiki
```

The plugin files are cloned to `~/.claude/plugins/obsidian-wiki/` on your machine. Updates land via `/plugin update obsidian-wiki`.
